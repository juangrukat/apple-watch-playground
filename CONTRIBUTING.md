# Contributing

Build and run `./scripts/check.sh` before proposing changes. Keep capture/transport separate from UI updates, bound queues/history, preserve source timestamps and physical units, and label simulated, saved, derived, stale and unsupported data honestly.

For a bug report, provide device model, OS/Xcode versions, connection type, reproduction steps, expected behavior and actual behavior. A simulated screenshot is preferable to personal telemetry. Do not post precise locations, Health records, audio, credentials, pairing codes, provisioning profiles or signed development artifacts.

Hardware performance claims should include capture rate, submission rate, reception rate, foreground/dim state, microphone state, connection type, duration and gaps. Do not treat a requested rate or a smooth animation as proof of sensor delivery.

Use your own signing team and bundle identifiers locally; do not commit that change. Contributions are provided under the repository's MIT license.
