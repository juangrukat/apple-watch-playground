# Changelog

## 0.1.0-alpha.1 — 2026-10-16

Initial experimental source release.

- Native Mac canvas with movable/snap-together cards, source-specific instruments, seven removable preset groups and custom presets.
- Watch app with dedicated touch/Crown controls, local output tests and optional sensor services.
- Direct Bluetooth and local HTTP transports with bounded queues, source timestamps, reconnection and acknowledged commands.
- Physical Watch pose, desk reference, Crown placement, independent numeric neutral and viewing alignment.
- GPS temporary-error recovery, location/heading quality metadata, unavailable-speed handling and circular compass smoothing.
- Optional iPhone diagnostic with configurable Mac host.
- Portable signing placeholders, build/setup documentation, simulated screenshots and regression checks.

Source release only. No notarized Mac installer, TestFlight build or App Store distribution is included. Background continuity, sensor availability and performance require testing on each physical device/setup.
